# Gudmundr public landing

Serves `gudmundr.com` via GitHub Pages. Contains only the public landing surface:

- `index.html` — public Designit home (rotating iðeas subtitle) · "Sign in with Gudmundr" → beta portal (apps host) → Gudmundr Gateway sign-in · request-access modal
- `beta.html` — redirect (meta refresh + JS + visible link) to the beta portal on the apps host (Railway URL until `apps.gudmundr.com` DNS is live)
- `CNAME` — `gudmundr.com` for the custom domain

Sensitive artifacts stay in the private `AIGenerated_HTML` repo (not published).
